# MyLifeFinance — releases

Aquí se publican las versiones instalables (APK) de MyLifeFinance, un gestor de finanzas
personales que vive entero en el teléfono: sin servidor, sin cuenta y sin permiso de Internet.
El código fuente está en un repositorio privado; este solo contiene las releases.

## Instalar y recibir actualizaciones con Obtainium

1. Instala [Obtainium](https://github.com/ImranR98/Obtainium/releases) (gratis, código abierto).
2. En Obtainium: **Añadir app** → pega `https://github.com/DieGogar007/MLF-releases` → **Añadir**.
3. Obtainium descarga la última APK y la instala. Android pedirá permitirle instalar apps
   desconocidas la primera vez.
4. Cada vez que aparezca una versión nueva aquí, Obtainium avisa y la instala con un toque.
   Los datos se conservan: el paquete y la firma son los mismos.

También puedes descargar la APK de la release más reciente y abrirla en el teléfono.

## Qué garantiza la firma

Todas las releases están firmadas con la misma clave. Android se niega a instalar encima una
APK con otra firma, así que una versión que no venga de aquí no puede sustituir a la instalada.
