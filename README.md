# MyLifeFinance — releases

Aquí se publican las versiones instalables (APK) de MyLifeFinance, un gestor de finanzas
personales que vive entero en el teléfono: sin servidor ni cuenta. El código fuente está en un
repositorio privado; este solo contiene las releases.

## Instalar la primera vez

Descarga la APK de la release más reciente en el teléfono y ábrela. Android pedirá permitir
la instalación desde el navegador la primera vez.

## Actualizar

Dentro de la app, en **Más → Actualizaciones**, pulsa **Buscar actualización**. La app
consulta aquí cuál es la última versión y, si es más nueva, la descarga y abre el instalador
de Android. Los datos se conservan: el paquete y la firma son los mismos. Es la única vez que
la app se conecta a Internet, y solo cuando tú lo pides.

También puedes descargar la APK de la release y abrirla en el teléfono, como la primera vez.

## Qué garantiza la firma

Todas las releases están firmadas con la misma clave. Android se niega a instalar encima una
APK con otra firma, así que una versión que no venga de aquí no puede sustituir a la instalada.
